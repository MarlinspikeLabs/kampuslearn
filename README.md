# KampusLearn

AI-powered academic platform for Nigerian tertiary institution students.

## Stack
- Frontend: Next.js 14 (port 3001)
- Backend: Node.js + Express (port 5000)
- Database: PostgreSQL 16
- AI: Claude API (mock during development)
- Process Manager: PM2

## Structure

├── backend/        # Express API
├── frontend/       # Next.js app
